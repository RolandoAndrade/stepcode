# Release 2.0.0 (sub-project 7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `stepcode@2.0.0` and the three `@stepcode/*` packages, merge `RolandoAndrade/v2` into `master`, move `stepcode.online` to the v2 editor Worker, turn the old proxy into a redirect, and point the academy at the published grammar package.

**Architecture:** Two halves. Tasks 1–4 are ordinary branch work (config, one editor change, a two-file redirect Worker, docs), each with its own test and review. Tasks 5–9 are the runbook of spec §6: the controller executes them in this session, one outward-facing step at a time, and the user says "go" before every publish, merge, or Cloudflare change. Nothing in the runbook is delegated to a subagent.

**Tech Stack:** pnpm 11 workspaces, Changesets 3, npm 11 (manual publish, provenance off), GitHub CLI, Wrangler 4.129 (custom domains on an assets-only Worker plus a tiny fetch-handler Worker), Cloudflare REST API for the Pages project (read with the OAuth token wrangler stores), Astro 7 in the academy. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-06-release-design.md` (all sections). Umbrella: `docs/superpowers/specs/2026-09-03-stepcode-v2-design.md` §7 step 7, §8.

```js
const TARGET = 'stepcode.online'

export default {
  fetch(request) {
    const url = new URL(request.url)
    url.protocol = 'https:'
    url.hostname = TARGET
    url.port = ''
    return Response.redirect(url.toString(), 301)
  },
}
```
